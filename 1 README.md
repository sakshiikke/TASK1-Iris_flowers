# Iris Flower Classification

## Project Overview
Iris Flower Classification is a Machine Learning project that predicts the species of an Iris flower based on its sepal and petal measurements.

This project is completed as part of the OASIS INFOBYTE Data Science Internship. It demonstrates the practical application of Python and Machine Learning classification algorithms.

## Objectives
- Understand and analyze the Iris dataset.
- Perform Exploratory Data Analysis (EDA).
- Visualize the relationships between different features.
- Build and compare Machine Learning classification models.
- Evaluate model performance using suitable metrics.
- Apply cross-validation and hyperparameter tuning.

## Dataset Description
The project uses the Iris dataset available in the Scikit-learn library.

- **Total Records:** 150
- **Input Features:** 4
- **Target Classes:** 3

### Features
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### Flower Species
- Iris Setosa
- Iris Versicolor
- Iris Virginica

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithms
The following classification algorithms are implemented:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree Classifier
4. Random Forest Classifier

## Project Methodology
1. Import the required Python libraries.
2. Load the Iris dataset.
3. Explore the dataset and understand its structure.
4. Perform data visualization and exploratory data analysis.
5. Split the dataset into training and testing sets.
6. Train the classification models.
7. Evaluate the models using accuracy, precision, recall, F1-score, and confusion matrices.
8. Perform 5-fold cross-validation.
9. Analyze feature importance and misclassified samples.
10. Apply hyperparameter tuning to improve model performance.
11. Compare the results of the classification models.
